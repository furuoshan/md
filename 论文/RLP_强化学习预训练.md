# RLP：强化学习预训练

## 论文

- 名称：RLP: Reinforcement as a Pretraining Objective
- 作者：Ali Hatamizadeh 等
- 发表：2025 年预印本；ICLR 2026
- 原文：https://arxiv.org/abs/2510.01265
- 官方介绍：https://research.nvidia.com/labs/adlr/RLP/

## 大致内容

RLP（Reinforcement Learning Pretraining）在预训练末期引入强化学习。模型先根据文本上下文生成思维链（CoT），再预测原文中的后续 token。奖励衡量这段思维链相对于不生成思维链的基线，是否提高了真实后续 token 的对数概率，即预测信息增益。基线通过指数移动平均（EMA）缓慢更新。

方法利用普通文本本身提供训练信号，不需要人工标注思维链，也不依赖额外的答案正确性验证器。它将生成有助于预测的思维链纳入训练目标，并与下一 token 预测结合。论文在 Qwen3-1.7B 和 12B 混合架构模型上研究其推理能力收益。

## 理解要点

- 常规预训练：直接学习根据前文预测后文。
- RLP：学习先生成有助于预测的思考，再预测后文。
- 与常见 RLVR 后训练相比：奖励来自文本预测的改善，而非最终答案通过数学验证或代码测试。
- 奖励表示预测效用，不等于思维链的逻辑正确性证明。
- 论文方法作用于预训练末期，不意味着从随机初始化开始全程使用强化学习。
